# Pokemon GO Data - Quick Access Guide
# 포켓몬고 데이터 - 빠른 접근 가이드

## 📍 Location / 위치

All Pokemon GO data is located in the `pokemon-go-data/` directory.

모든 포켓몬고 데이터는 `pokemon-go-data/` 디렉토리에 있습니다.

## 📂 Available Files / 사용 가능한 파일

### Documentation / 문서
- [README.md](pokemon-go-data/README.md) - Complete documentation in English and Korean
- [UPLOAD_SUMMARY_KR.md](pokemon-go-data/UPLOAD_SUMMARY_KR.md) - Korean summary document

### Data Files / 데이터 파일
- [pokemon_list.json](pokemon-go-data/pokemon/pokemon_list.json) - 21 Pokemon with complete stats
- [events_2025.json](pokemon-go-data/events/events_2025.json) - 2025 event calendar
- [official_addresses.json](pokemon-go-data/locations/official_addresses.json) - Niantic offices and official links
- [items_list.json](pokemon-go-data/items/items_list.json) - All in-game items
- [moves_list.json](pokemon-go-data/moves/moves_list.json) - Pokemon moves database
- [game_mechanics.json](pokemon-go-data/mechanics/game_mechanics.json) - Game systems and mechanics

## 🚀 Quick Start / 빠른 시작

```bash
# Navigate to Pokemon GO data directory
cd pokemon-go-data/

# View Pokemon data
cat pokemon/pokemon_list.json

# View events
cat events/events_2025.json

# View all documentation
cat README.md
```

## 📊 Data Summary / 데이터 요약

- **Total Pokemon**: 21 (Gen 1-3 / 1-3세대)
- **Events**: Complete 2025 calendar / 2025년 전체 일정
- **Items**: 50+ items / 50개 이상의 아이템
- **Moves**: 30+ moves / 30개 이상의 기술
- **Languages**: English & Korean / 영어 및 한국어
