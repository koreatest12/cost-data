🤖 Dependabot 설정

프로젝트의 모든 의존성을 자동으로 최신 상태로 유지합니다.

  • GitHub Actions: 매일 오전 9시 (KST) 자동 업데이트
  • Python 패키지: 메인 프로젝트 및 KCA 모니터 스크립트 의존성 관리
  • Maven 의존성: 메인 프로젝트 및 4개 마이크로서비스 개별 관리
  • Docker 이미지: 매주 월요일 베이스 이미지 업데이트
  • 자동 병합: 패치/마이너 업데이트는 자동 승인 및 병합
  • 보안 알림: 취약점 발견 시 자동 이슈 생성
  • 주간 보고서: 매주 월요일 의존성 상태 보고서 생성
